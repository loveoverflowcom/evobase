# EvoBase component contract · M3 Expressive reference

Status: target design, not implemented Leptos/CMP UI. Source snapshot: EvoBase develop@4cb5873200f4d735b17b75fdd3cb88c2efdbb322; vision issue #1 read 2026-10-01. The fixture prototype has no auth, backend, persistence, provider delivery or native execution.

## Attention hierarchy

- Product vocabulary is plain Vietnamese. Technical concepts belong in this specification, diagnostics or a deliberate Advanced disclosure. Runtime copy never explains URL selectors or database roles.
- Blue primary marks one focal action. Mint tertiary marks a task priority, not arbitrary success. Error/warning/success each have semantic roles and words/icons.
- Use contained lists for actual work. Hero shape can express priority but must leave useful first-viewport content. The refined Runtime home has two approval items and two recent orders, not equal-size marketing cards.
- Default cards have no outline or shadow. Surface roles provide grouping. Dividers are justified in dense grids. Focus, invalid fields and relation paths may use outlines.
- Shape differentiation: 32px overview/priority; 24px main containers; 16px work rows; 12px fields; pill primary action; square-to-rounded connected selection. A repeated rounded card is not sufficient evidence of M3 Expressive.
- Deliberate intensity: low for tables/runtime lists, medium for approval/form focus, high only overview or a completed decision. Avoid expressive motion on every cell.

## Canonical token source and generation

`source/tokens.json` is an EvoBase custom authored schema, not a DTCG JSON shape. It owns paired color roles, type, shape, space, layout, state and motion. Legacy Flutter used Colors.blue (#2196F3) through ColorScheme.fromSeed. The new role values are curated, blue-family authored values, not claimed HCT output or official Material Theme Builder export.

Future foundation PR: import this file into a checked-in generator; deterministic output CSS custom properties for Leptos and Kotlin ColorScheme/Typography/Shapes for CMP. Preserve semantic names and exact values. Test every role, output identity and light/dark round-trip. Do not fork palettes per app or regenerate independently. Dynamic color is deferred until readable paired semantic roles and non-color status meaning are protected.

Reference file `source/tokens.css` is generated by `build.py`; source/style.css reads role names without component-specific hex values. Open Sans Version 1.10 is bundled under Apache-2.0 (full license plus original attribution notice). Runtime numbers use tabular numerals. Compact data is 13px/20; normal body 14px/22; normal touch controls remain 48px.

## Data-grid interaction contract

1. Stable `record_id` and `field_id` own selection/editing. Sorting, row paging, rename and reorder cannot retarget an in-progress edit.
2. Display currency unit in header and/or each value. Current reference uses `Tổng (VND)` plus ₫ fixture values. No scientific value without units.
3. Single selection is tonal; focused cell has a 3px outline plus textual context. Focus and selection are different states.
4. Enter/F2 opens edit. Escape cancels without mutation. Tab commits valid edit and moves; Arrow keys navigate only outside active text/IME composition. No premature commit during compositionstart/compositionend.
5. Paste/import map typed fields. Ref text matching can return unique, missing or ambiguous; latter two require resolve, never guess. Show per-cell/dataset diagnostics; preserve the original input.
6. Undo has an explicit boundary. Local edit undo is separate from reverting a persisted business command. Current permissions, revisions and side-effect limitations still apply.
7. Virtualization needs semantic row/column position, focused row retention and a tested screen-reader model. Prototype table is not a tested virtualized ARIA grid.
8. Relation picker only retrieves authorized projections, writes target IDs and independently rechecks target/type/scope on command commit. Anonymous lookup, all-row fallback and inferred grant from relation are forbidden.

## Runtime interaction contract

- Compact target design is CMP native, 390px reference width; its PNG is a static design, not a native screenshot. Web responsive prototype illustrates anatomy only.
- Runtime home uses contained task/order rows. An order row navigates to detail; a task row navigates to approval. Primary CTA creates a draft.
- Detail/form/approval/inbox have visible navigation-up. Browser history, Android Back and iOS edge swipe return to origin; unsent draft/reject reason is preserved or explicitly discarded. Closing a sheet never becomes Approve/Reject.
- Save Draft and Submit are separate commands. Pending/local/offline state never says Sent. Success requires a checked server receipt; repeated same immutable intent returns the original committed receipt under current grants, even if live data revision advanced.
- Readable business total is an authorized output. Do not sum only visible children and present it as the full business total. Show an unavailable/denied state when policy requires it.
- Captured unit price is visibly distinct from current Product price. Later catalog price changes do not silently rewrite history.
- Approval checks current authority and the reviewed record revision at commit. Conflict forces refreshed review.

## Motion and adaptive behavior

State change: 160ms; container/navigation 280ms; intentional expressive emphasis up to 420ms. These are authored design values, not asserted official physics-token values. Press morph must not move adjacent labels or delay business actions. Reduced motion removes springs/transforms and uses immediate state feedback. No looping success/loading decoration that hides an actual status.

Below 600px: Runtime one pane; safe-area bottom CTA and navigation; modal can become full sheet. Builder becomes a read-only summary with a wide-screen handoff, not a squeezed complete modeling canvas. 600–999px: list/detail can stack, inspector collapses. 1000px+: rail + content + optional inspector. Support 200% zoom and long VI/EN labels before calling the future adapter done.
